# Archived Desktop Launcher Notes

> **Archived:** These launcher instructions describe a former integration and do not match the current web application. The current Laravel routes do not register `/fms-portal-entry`, `LoginAccessMiddleware` is not active, and the desktop launcher source files are not part of the supported application workflow. Do not build or distribute launchers using these instructions.

Use the browser-based Laravel application instead:

- [Quick start](../QUICKSTART.md) for local development.
- [Deployment guide](../DEPLOYMENT_GUIDE.md) for a supported web deployment.
- [Security notes](../SECURITY_SETUP.md) for the current session and role-based access boundaries.

The adjacent Android README is archived for the same reason. Legacy `FMS_*` settings remaining in `.env.example` do not enable or protect a route in the current application.
